# INS-0001 plugin 化 = 漏斗, 不是收入

## 事实
- `project-journal` 是 Sapiens AI bundled skill, 内部代码/台账不可直接对外
- 做 DeepSeek/Agent 插件需先脱敏成社区版(去品牌/去内部工单/去内部路径)
- 公开数据参考(163/腾讯 2026-04 报道): "3.3 万 Skills 大多死在安装这一步", 安装数是不可信北极星
- 分发渠道(DeepSeek/ClawHub)不在我们手里

## 判断
- **插件壳(层 1) = 0 直接收入**, 免费, 当获客漏斗
- **托管版 SaaS(层 2) = 主收入**, $5–10/月订阅, 需安装 → 团队激活 → 订阅三层转化
- **企业版(层 3) = 利润层**, $50–200/月, 客群窄
- 短期(30 天): 别押 plugin, 集中 repo-watch S2(GitHub star/clone 指标更硬)
- 中期(3–6 月): 当 side bet, 脱敏社区版挂 GitHub, 看安装数再决定托管
- 长期: plugin 是分发漏斗, 不是收入本身

## 止损
- 30 天安装 < 20 即停 plugin 路径(投入产出比不划算)
- 6 个月安装 < 100 且托管转化 < 1% 即停
