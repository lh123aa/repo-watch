# IN-0002 变现路径与具体方法

## 判断（不吹）
repo-watch 是"多仓库上游更新焦虑"的窄需求工具。本身不发财，是**验证你能不能把小工具做出真实需求**的赌注。变现结构 = 漏斗（免费层）→ 真收入（托管 SaaS）→ 薄市场（企业），并辅一条**当下就能走的副线**（案例/内容资产）。

## 四层变现模型

### L1 免费开源（当前 S2 验证中，$0）
- 角色：漏斗 + 背书 + 需求验证裁判
- 现状：tag v1.0.0 已 push，release 待用户手动发布（60 秒），release.zip 由 `.github/workflows/release.yml` 自动挂
- 关键动作：30 天数据回收 2026-11-08（已设提醒）

### L2 托管 SaaS（$5–10/月，唯一可能的真收入）
**卖什么（不是再卖一次代码，是卖"免部署 + 跨平台"）**
- 免部署：用户不装 Python、不写守护、不开机自启 → 网页/dashboard 托管扫描
- 跨平台：Mac / Linux / 服务器 也能用（开源版是 Windows-only）
- 多账号：一个 dashboard 管 N 个 GitHub/GitLab 账号的仓库
- 可选增值：webhook、Slack/Discord 推送、PR 提醒、团队共享视图

**架构（最小可行）**
```
[用户 GitHub Token] ──> [GitHub API 轮询 worker (FastAPI + APScheduler)]
                ──> [Postgres: repos / updates / users / subscriptions]
                ──> [React dashboard: 仓库列表 / 更新流 / 订阅管理]
                ──> [Stripe Billing: 月付 $5–10 / 年付 8 折]
```
- 部署：1 个 VPS ($5/月) + 1 个 Postgres 托管 ($10/月) 起步，月成本 <$30
- 免费层：3 个仓库 + 30 分钟扫描 → 付费解锁无限仓库 + 1 分钟扫描 + 跨平台

**定价（阶梯）**
| 档位 | 月费 | 内容 |
|---|---|---|
| Hobby | $0 | 3 仓库，30 分钟扫描，GitHub only |
| Pro | $7 | 无限仓库，5 分钟扫描，多账号，Slack 推送 |
| Team | $19 | 5 席位，共享 dashboard，审计日志 |

**启动条件（S2 数据触发，不要现在做）**
- 触发线：30 天安装 ≥ 100 且 ≥ 10 人 主动 ask "有没有 mac 版 / 网页版"
- 或：S2 到期后 star ≥ 50 → 立即启动 L2 MVP（2 周 sprint）

### L3 企业版（$50–200/月，薄市场，默认不做）
- 只在 L2 有 ≥ 3 家 Team 付费且有人问"私有部署"时再开
- 卖：私有部署 + SSO + 审计 + 多租户隔离
- 现实：一个人卖不动，先放着

### L4 案例 + 内容资产（**当下就能走，不等 S2**）
- 把"想法 → 574 行代码 → 开源 → S2 数据 → 止损/进 L2"全程写成**公开案例研究**
- 渠道：
  - GitHub 仓库自带（README 已经能引到 project-journal/）
  - 知乎 / 即刻 / X 发 3–5 篇"build in public"短文
  - Sapiens 生态 / Sapiens 渠道内的项目展示页
- 变现：
  - 不直接卖，但**提升你"能把想法落地成开源项目"的可证明能力** → 接外包 / 求职 / 接 Sapiens 生态项目时值钱
  - 案例本身可以打包进 `publish/` 脱敏资产包（project-journal §13.06），$29–99 区间，卖给"想做开源但没做出闭环"的人
- 关键动作：S2 到期后无论成败，都出 1 篇 3000 字案例 + 1 个脱敏资产包

## 决策树（S2 到期 2026-11-08 对照）

```
                  S2 数据
                      │
        ┌─────────────┴─────────────┐
        │                          │
   star≥50 或               star<10 且
   clone≥200               clone<50
        │                          │
   进 L2 MVP                停 L1/L2
   (2 周 sprint)            推广
   免费层+Pro 上线                │
        │                   只保留 L4 案例
   Stripe 上线                  资产包
        │                          │
   月费 ≥ $100                带案例资产
   且 ≥ 5 付费用户            接外包/求职
        │                          │
   继续 L2                    不恋战, 收工
        │
   有 ≥ 3 家 Team 付费
   且有人问私有部署
        │
   开 L3 企业
```

## 关键数字（进 metrics.csv）
- 当前状态（2026-10-09）：stars=0, private=False, S2 时钟 0/30 天
- 触发 L2：30 天安装 ≥ 100 且 ≥ 10 人 ask 跨平台
- 触发 L3：L2 月费 ≥ $100 且 Team ≥ 3 且 私有部署问询 ≥ 1
- 止损 L1+L2：S2 到期不达标 → 停推广，只保留 L4 案例资产

## 现实提醒（不吹）
- L2 天花板：小众 SaaS，月入几百到几千刀，**不是**"财务自由"
- L4 当下就能启动，不等 S2：3–5 篇短文 + 1 篇 3000 字案例 + 1 个脱敏资产包
- 唯一稳的变现是 L4（可证明能力 + 案例资产），产品本身（L1/L2）是期权
